## 中文

夜间息屏守护首个 GitHub 发行版，支持中文 / English 即时切换。

- 手动开始，五秒倒计时；保持电脑运行，意外亮屏时再次请求关屏。
- 操作键鼠结束守护，托盘月亮图标左键单击打开。
- 记住语言选择；不接管系统月亮键，不添加开机自启。
- 开源代码、原创图标和文档采用 MIT 许可证。

**下载使用：** 选择 `NightScreenGuard-1.1.0-win-x64.zip`，解压后运行 `NightScreenGuard.exe`。需要 Windows 10/11 x64 和 .NET Framework 4.8；程序未做代码签名。

`NightScreenGuard-1.1.0-source.zip` 是源码包。`SHA256SUMS.txt` 用于校验附件完整性。

16 项本地自动检查和双语界面检查通过。本软件无法保证零闪亮；Windows 报告亮屏不代表外接显示器一定已实际点亮。

## English

First GitHub release of Night Screen Guard, with live Chinese / English switching.

- Manual start with a five-second countdown; keep the computer working and request power-off again after unexpected display wake.
- End guarding with keyboard or mouse input; single-click the moon tray icon to open the app.
- Remember your language without rebinding the Windows moon key or adding startup entries.
- Code, original icon and documentation are MIT licensed.

**Download:** choose `NightScreenGuard-1.1.0-win-x64.zip`, extract it and run `NightScreenGuard.exe`. Requires Windows 10/11 x64 and .NET Framework 4.8. The executable is unsigned.

`NightScreenGuard-1.1.0-source.zip` contains source. Use `SHA256SUMS.txt` to verify attachments.

16 local automated checks and bilingual UI checks passed. Zero flashes cannot be guaranteed; Windows display-on events do not prove physical monitor recovery.
